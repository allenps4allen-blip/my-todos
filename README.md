# my-todos

A Claude Code mod: a red-bordered dashboard panel with your to-do list, usage limits, cost, and pasted images on the far right. Use `/todo add|done|remove|clear` for the list. Needs a wide terminal (about 144 columns).

## Install

In a terminal session of Claude Code:

```
/plugin install my-todos --marketplace allenps4allen-blip/my-todos
```
